# 🌐 Proyecto: Calidad del Software

Este proyecto web fue desarrollado como una evidencia académica para la asignatura **Calidad de Software**, del programa de **Ingeniería de Sistemas** en la **Corporación Unificada Nacional de Educación Superior (CUN)**.

El sitio presenta de manera estructurada los principales temas asociados a la calidad del software, acompañados de una interfaz visual limpia y moderna, ideal para fines educativos y de exposición.

---

## 📘 Contenido del Sitio

El proyecto está compuesto por varias páginas HTML interconectadas, cada una dedicada a un tema específico:

| Página | Descripción |
|--------|--------------|
| **index.html** | Página principal o de inicio del sitio. Presenta la introducción al tema. |
| **calidad.html** | Expone los conceptos fundamentales de la calidad del software. |
| **principios.html** | Describe los principios básicos de la ingeniería de calidad. |
| **modelos.html** | Contiene información sobre modelos de calidad (ISO 9126, McCall, Boehm, etc.). |
| **estandares.html** | Explica los estándares más utilizados para la gestión y aseguramiento de la calidad. |
| **evaluacion.html** | Página interactiva con un formulario o cuestionario para evaluar conocimientos. |
| **contacto.html** | Incluye un formulario de contacto con botón de retorno al inicio o evaluación. |
| **conclusiones.html** | Presenta las conclusiones generales del trabajo académico. |

---

## ⚙️ Tecnologías Utilizadas

- **HTML5** → Estructura del sitio  
- **CSS3** → Estilos y diseño visual (archivo `style.css`)  
- **JavaScript** → Funcionalidad e interacción (`script.js`)  
- **Git / GitHub** → Control de versiones y publicación  
- **Carpeta `Imagenes/`** → Contiene los recursos gráficos del sitio

## 🚀 Cómo Ejecutar el Proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/AlonsoVertel/CALIDAD-DEL-SOFTWARE.git
   ```
2. Abre la carpeta del proyecto:
   ```bash
   cd CALIDAD-DEL-SOFTWARE
   ```
3. Abre el archivo `index.html` en tu navegador web.

---

## 🎯 Objetivo del Proyecto

Este proyecto tiene como propósito **aplicar los principios de la calidad del software** mediante un desarrollo web estructurado, donde se ponen en práctica los conceptos de:

- Correctitud, eficiencia y mantenibilidad.  
- Documentación clara y coherente.  
- Interfaz accesible y usabilidad adecuada.  
- Aplicación de estándares de calidad y buenas prácticas.
